BizLink — How to Run (Windows + macOS). Verified 2026-10-15.

Prerequisites (both): Git, Composer, Node 20+, PHP 8.2+ with pdo_mysql.
  Windows: XAMPP PHP (C:\xampp\php) or standalone PHP; enable pdo_mysql + mysqli in php.ini.
  macOS:   brew php (pdo_mysql included) + Node via nvm/‍brew.

Repo layout (clone anywhere; examples use <repo>):
  <repo>/backend   Laravel API (MySQL `bizlink`)
  <repo>/frontend  React 19 + Inertia + Vite + Tailwind v4

Ports (OS defaults — DB_PORT in backend/.env must match YOUR MySQL):
  Windows: MySQL 3307 (see start-bizlink.ps1, C:\temp\bizlink-mysql), Laravel :8000, Reverb :8080, Meili :7700
  macOS:   MySQL 3306 (community server), Laravel :8000, Reverb :8080, Meili :7700
  If your MySQL differs, set DB_PORT accordingly. APP_URL=http://localhost:8000 both.

Quick start
  Windows (recommended): right-click start-bizlink.ps1 > Run with PowerShell.
    It kills stale :8000/:8080/:5173/:7700, starts MySQL 3307 + Meili (auto-downloads
    meilisearch.exe once) + Laravel + Reverb + Vite. Then do Step 4 once.
  macOS: no .ps1 — 3 terminal tabs (Step 5 below).

Step 1 — Services
  Windows: via start-bizlink.ps1 (above), or manually: mysqld (MySQL Server 8.0),
    meilisearch.exe --db-path=C:\temp\meilisearch_data
  macOS: brew services start meilisearch; sudo /usr/local/mysql/support-files/mysql.server start

Step 2 — Database (fresh machine only)
  CREATE DATABASE IF NOT EXISTS bizlink;
  CREATE USER IF NOT EXISTS 'bizlink'@'localhost' IDENTIFIED BY 'Bizlink123!';
  GRANT ALL PRIVILEGES ON bizlink.* TO 'bizlink'@'localhost'; FLUSH PRIVILEGES;

Step 3 — backend/.env (never commit secrets)
  DB_HOST=127.0.0.1, DB_PORT=<yours: 3307 Win / 3306 Mac>, DB_DATABASE=bizlink, DB_USERNAME=bizlink
  GOOGLE_CLIENT_ID/SECRET (+REDIRECT http://localhost:8000/api/auth/google/callback)
  GCP Audience (Testing): add every demo Google account as Test user, else 403 —
  login scopes pass but calendar.events (Meet) is sensitive and blocks non-test-users.
  Meet callback http://localhost:8000/meet/callback must be a registered redirect URI.

Step 4 — First setup (backend dir). WARNING: db:seed only on FRESH DB (rewrites demo posts).
  php artisan key:generate && php artisan migrate && php artisan db:seed   (fresh only)
  php artisan admin:ensure    (idempotent; guarantees admin@bizlink.ph + Admin role for demos)
  php artisan config:clear
  Sanity: php artisan test (green) + php artisan route:list --name=comments

Step 5 — Dev servers (if not using the .ps1)
  Tab 1: cd backend  && php artisan serve --port=8000
  Tab 2: cd backend  && php artisan reverb:start --port=8080   (realtime only)
  Tab 3: cd frontend && npm run dev   (first time: npm install)

Step 6 — Open http://localhost:8000 (NOT :5173 — Vite serves assets; Laravel renders).
  Demo accounts: admin@bizlink.ph (Admin) / brand@bizlink.ph (Manager) / demo@bizlink.ph (User).
  Google first-timers land as entrepreneur/User via the welcome role flow.
  Verify: 390x850 mobile (bottom nav, sticky search), login = exactly 1 toast, theme toggle survives refresh.
